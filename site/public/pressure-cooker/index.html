AI and code

Each does the part it is good at

The model does

  • Matches an item it can't find (“tenderstem”) to one on the store list, for you to confirm
  • Picks a few recipes from a shortlist code has already ranked and filtered
  • Writes a one-line reason for each pick, rejected if it contains a number
  • Chooses search terms and when to stop, in search further

Code does

  • All package math and the shopping list
  • Match counts and ranking
  • Dietary filters, which fail closed
  • Suggested chips and the “results are weak” rule
  • Checking every recipe the agent finds, and every limit it runs under

Under the hood

The AI and coding elements

Claude Haiku 5.5Claude Sonnet 5.5Anthropic APITheMealDB APITypeScriptNetlify FunctionsNetlify Blobs

AI

Mapping
Claude Haiku 5.5, the lowest-cost model. It may only answer with a name from the store list, or none.
Picks
Claude Sonnet 5.5, choosing from a code-ranked, diet-filtered shortlist. Any id outside it is dropped.
Search further
Claude Sonnet 5.5 with four tools: search by ingredient, search by name, check a recipe, finish. Code runs every tool.
Structured output
Answers come back as JSON against a schema, then code checks them again.

Code

Engine
A rule-based ingredient parser, unit conversion, package rounding, diet table and ranking, all in TypeScript.
Server
One Netlify Function holds the API key, the spend caps and the fetch rules. It runs no schedule.
Your data
Your household lives in your browser. The server keeps the recipe pool, the day's spend and cached recipe data. No accounts, analytics or cookies.
Recipes
From TheMealDB's public API, which invites this use and asks for credit and a link back. Both are given.
Scorecard and limits

What is measured, and what is not

Package math

Checked line by line against the original version on every recipe it could price: 634 lines, all identical.

Diet filter

A 20-recipe test set: no restricted recipe gets through, and anything unmapped says “can't confirm.”

Limits

$0.10 per search further, $3 a day, 10 AI actions per device per day. Tested with the caps set to one cent.

A filter, not a guarantee. Diet settings rule recipes out in code, but anything the table can't vouch for says “can't confirm, check the label.” It makes no health claims. Always read the label when it matters.
